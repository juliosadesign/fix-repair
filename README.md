# Fix Repair

Interface frontend da plataforma acadêmica **Fix Repair**, iniciativa ligada à **Thera** e à **UEMA** para organização de solicitações de suporte técnico e fluxo de atendimento aos alunos.

- **Aplicação em produção:** [fix-repair-tau.vercel.app](https://fix-repair-tau.vercel.app/)

## Stack

- **React** + **JavaScript**
- **Deploy:** Vercel

## Estrutura

```text
fix-repair/
└── frontend/   # Aplicação web React
```

## Como rodar localmente

```bash
git clone https://github.com/juliosadesign/fix-repair.git
cd fix-repair/frontend
npm install
npm run dev
```
